SMS observer (Linux/WSL, one ROM and native core per process)

Run from the repository root:
python3 tools/rom-audit/observe_sms.py --rom /absolute/path/game.sms --output build/verification/sms-audit/game.json --frames 1200 --core build/linux/core/genesis_plus_gx_libretro.so

This is separate from the Mega Drive observer. It reads source ROM bytes once and passes a private copy to the core. It never writes source ROMs, BIOS files, user saves or settings. Results and native build products stay under ignored build/. No emulator build or GUI is started.

Requirements: Python3, NumPy, Pillow, GCC, nm and a native core with its local ELF symbols intact. Default source build/deps/genesis-plus-gx-32x-linux must match the binary ABI. Z80 and SRAM types are compiled directly from headers. romhw_t and the anonymous current-slot structure, private to sms_cart.c, are extracted verbatim into an ignored generated header before compiling. JSON records ELF SHA, current source SHA, extracted type SHA and compiled sizes/offsets. The current source tree is not a compiled-source attestation; the ELF hash identifies the actual binary.

Default input uses SMS button1 (libretro B mask1), button2 (A mask256) and Right mask128. There are no Start/Pause pulses. Button1 at zero-based120 and480, button2 at300, then movement/button intervals after600. --no-input disables defaults; repeated --buttons FRAME:COUNT:MASK adds intervals. --option KEY=VALUE overrides native options; --no-hooks makes a control run. --frames, --checkpoints, --no-png, --png-width and --bios-dir are supported. BIOS boot is disabled by default; no BIOS import occurs. Each caller must use a distinct result path.

Outputs: complete PCM16LE SHA and counters; sampled RGB video sequence SHA, stage hashes/colors and PNGs at120/600/final; effective fps/sample rate, native system, region_code, vdp_pal, actual YM2413 enabled/automatic bits and detected SMS region hint. Initial/final and checkpoint hardware records contain Z80 PC/halt/cycles, selected cartridge and active-slot mapper IDs/names/pages/FCR, all64 1KiB read/write page descriptors and native mapper-context size/SHA. Page descriptors identify ROM-buffer offsets, loaded-content bounds, SRAM and work RAM without depending on process addresses. Native mapper context is a read-only snapshot; it is not a full save-state restore test.

Native forwarding observes the actual z80_writemem callback. It restores the original callback pointer while calling it with unchanged arguments, then follows any replacement made by native code. Write-port callback forwarding follows memory-control changes as well; ports3E/3F are recorded. Every cartridge-range write belowC000 and allFFF0..FFFF candidate writes are eligible; ordinary RAM writes are counted. Actual FCR/8KiB bank changes and standard control addresses get priority. Rows retain addresses, handlers, first/last CPU PCs and frames, all observed byte values, calls and mapping-change counts. Rows are capped2048; nonpriority cartridge noise is capped256 addresses, with omitted-call counters. First256 unique events include before/after FCR and6 bank anchors. Direct reads and emulation timing are untouched.

Controls: ordinary Sonic SMS (SEGA mapper16) and Cosmic Spacehead (Codemasters19),1200 frames each with/without hooks, matched sampled video SHA, every PCM byte, all Z80/hardware checkpoints and all64 memory maps exactly. Evidence: build/verification/sms-audit/observer-control-validation.json. A completed bounded run is not a full-game compatibility verdict.
