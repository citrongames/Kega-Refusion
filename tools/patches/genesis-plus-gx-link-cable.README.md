# Link Cable native integration

The cable pin model is derived from [Linn1024/zero-tolerance-link](https://github.com/Linn1024/zero-tolerance-link), commit `1ab47c4b973471174f6ae6275a3f59953761f3d9`, specifically its `core/io_ctrl.c` changes and [implementation notes](https://github.com/Linn1024/zero-tolerance-link/blob/main/docs/implementation.md). The original prototype used Genesis Plus GX commit `27426f00aa68f9f358c86919e8a40985326fa05b`. Credit remains with Charles MacDonald, Eke-Eke, component authors, and Linn1024. These adaptations retain the existing Genesis Plus GX default license, including its noncommercial redistribution and complete corresponding source requirements. This is not an MIT-licensed implementation. Preserve the full core/component license notices in distributed source.

The two normal Mega Drive consoles connect at controller port B. D0–D3 pass through, TR/TH cross, and the disconnected TL input reads high. Input-configured peer pins are pulled high. Local output direction overrides peer input. A falling peer TR becomes local TH; control bit 7, TH input direction, and VDP register 11 bit 3 gate IRQ2. The games implement their own protocol: there are no ROM patches, title fingerprints, or startup states.

`genesis-plus-gx-link-cable.patch` adds process-local connection/coroutine hooks. Disconnected cores keep the existing execution and IRQ behavior, apart from null-callback guards. Connected cores retain external pending IRQ2 separately from the VDP level: 2 plus 4 must not become 6. Acknowledging IRQ2 does not clear HINT/VINT. Linked STOP idle time also yields to observe incoming edges. The scheduler uses instruction boundaries; a deadline can overrun by one complete 68000 instruction. Port-data/direction reads and writes additionally synchronize before access. Larger instruction quanta are not proven equivalent: a peer can otherwise produce multiple transitions between polls.

Connection initializes the edge baseline without generating an interrupt. `link_latch` packs previous TH in bit 0, external pending in bit 1, and VDP IRQ level (0/4/6) in bits 8–10. The host restores both native machines, reconnects their pointers, then restores both latches at a completed frame boundary. Callbacks, peer addresses and coroutine stacks never enter saved state.

`genesis-plus-gx-link-audio-state.patch` adds optional `retro_kegarefusion_link_audio_size/save/load` exports. The fixed 496-byte `KRLKA001` extension accompanies each native state. It encodes all scalars in little endian, including binary64 filter values: audio settings/rate, FM output history and busy deadline, Blip factor/phase/integrators/all 18 impulse-tail samples, both EQ histories, and low-pass history. It contains no pointer, struct-padding or native `long` dump. Ordinary GPX state bytes and compatibility identifiers remain unchanged. The extension accepts only completed MD audio frames without auxiliary streams; it validates the complete payload before mutation. The enclosing paired-state format must version this new contract and restore native state before its audio extension.
