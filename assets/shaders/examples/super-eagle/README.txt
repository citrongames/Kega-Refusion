Super Eagle — пример пользовательского GLSL-пресета / custom GLSL preset example

Видео → Шейдер → Загрузить GLSL-пресет… → super-eagle.glslp.
Keep the three .glsl/.glslp files together. First pass: SuperEagle at 2x,
nearest sampling. Second pass: stock output with linear sampling.

The preset and shader files were supplied by the user, unchanged, 2026-11-03.
