Aq Renkan Awa / Ah Q Lianhuan Pao — последовательные сохранения
2026-11-02. Реализовано в версии 0.14.6.

ПОДТВЕРЖДЁННЫЙ ПРОТОКОЛ
ROM: CRC32 2C6CBD77, размер 1 МиБ, пара checksum 0x8104:0x0517,
CRC32 первых 64 КиБ — 34E04945.
В коде предусмотрены четыре записи по 32 байта: полный образ — 128 байт.
Процедуры 0x0FF322 / 0x0FF34A / 0x0FF362 используют порт 0x400001:
CS — бит 2, CLK — бит 1, DI — бит 3, DO — бит 0.
START + 8 бит команды, EWEN 0x30, READ 0x80 | addr, WRITE 0x40 | addr,
64 адреса по 16 бит, последовательное чтение и ожидание ready соответствуют
протоколу 93C46. Подробные адреса вызывающих процедур приведены в
pirate-audit-groups-2-4.txt.

РЕАЛИЗАЦИЯ
Повторно используется существующий eeprom_93c.c; адаптер только переносит
DI из бита 3 в бит 0. Распознавание узкое: размер, оба checksum и CRC32
первых 64 КиБ. Аппаратная модель не меняет ROM. Прочие игры и SMS 93C46
не переключаются на новую модель.
Серийный порт не включает параллельную SRAM. Эта плата не обслуживает
TIME-переключения, включая словную запись в 0xA130F0 и её алиасы.
После загрузки старого состояния ошибочные параллельные карты очищаются.
Обработчик одного байтового порта сохраняет чтение остальных адресов,
включая CD BIOS в Mode 1.
Power reset очищает протокол и разрешение записи, сохраняя батарейные байты.
Soft reset не подаёт сброс питания на EEPROM. Флаг очищается при gen_init.
Нет работы на каждом кадре, выделений памяти при обращениях или прямой
записи на диск из устройства. Хранение ведёт существующий BatterySave:
сравнение данных, ограничение частоты, атомарная запись и одна предыдущая
резервная копия.
Публичная ёмкость SRAM остаётся равной 64 КиБ ради совместимости со старыми
контейнерами. Сам чип использует 128 байт; текущий BatterySave при изменении
пишет 64 КиБ.

СОСТОЯНИЯ И СОВМЕСТИМОСТЬ
В последних 160 байтах существующего STATE_SIZE только для Aq помещён
опциональный упакованный блок KRAQ93C!: версия, длина, CRC32, поля протокола
и 128 байт памяти. Публичный размер состояния и начало блока 32X не меняются.
Указатели и выравнивание C-структур не сериализуются. Проверка блока
происходит ДО system_reset; неправильные версии, CRC и счётчики отклоняются.
Состояния без маркера читаются как старые: протокол сбрасывается, текущие
батарейные байты сохраняются. Старые обёртки movie/rewind затем продолжают
восстанавливать свою внешнюю SRAM. Для слотов сохранений оставлен прежний
идентификатор совместимости.
Для Aq выделены отдельные суффиксы ABI записи и сетевого состояния.
ABI записи теперь обновляется после загрузки игры: прежнее однократное
чтение до load не позволяло объявлять аппаратно-зависимую совместимость.
Другие игры сохраняют прежний ABI.
Точные старые записи Aq могут расходиться: до изменения устройство
отсутствовало. Политика предупреждения о версии и попытки воспроизведения
сохранена.

ПРОВЕРКА
core_integration_tests --aq-microwire: PASS.
Оригинальный сгенерированный ROM для 68000 передаёт команды через реальную
карту памяти CPU. Проверены запрет WRITE без EWEN, EWEN, WRITE, READ
(нулевой dummy bit + 16 бит), переход 63 → 0, EWDS, восстановление после
7 бит WRITE и 5 бит READ, отклонение плохой версии без изменения состояния,
старое состояние без блока с сохранением батареи, soft/power reset,
батарейный файл и переход на обычный ROM без утечки ABI или модели.
Тест содержит попытки ошибочного включения параллельной SRAM через
0xA130F0 и 0xA13060. Исходных игровых данных в диагностике нет.
Реальные ROM не изменялись.
Настоящие подпрограммы ROM (EWEN / write64words / read64words) успешно
записали и прочитали все 128 байт; состояние восстановило их после
контролируемого изменения. Проверено в MD, CD, 32X и CD + 32X.
Входы и стек задавались только в RAM; ROM не патчился.
Это проверка подпрограмм, а не полное прохождение меню сохранения.
