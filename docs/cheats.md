# Читы: CHT и ручной поиск (0.20.0)

Меню «Читы» содержит прежнее окно «Коды / Game Genie…» и отдельный «Поиск читов…».
Загрузка CHT добавляет записи к текущему списку, исключает дубли и оставляет импортированные
читы выключенными. «Сохранить CHT…» экспортирует текущий список, описания, составные коды
и выбранные галки в формат RetroArch. Экспорт сам по себе не применяет изменения к игре.
Составной код с `+` — одна запись с одной галкой; в ядро передаются отдельные компоненты,
чтобы не переполнить его короткий буфер. Общие компоненты включённых групп применяются один раз.

Автоматическое хранение — `cheats/<имя ROM>.json` в папке данных, без хеша. Запись атомарная,
только после изменения списка. Список и галки восстанавливаются при открытии игры.
Открытие и закрытие окон, каждый кадр и каждый поиск ничего не записывают на диск.

Поиск работает вручную по основной RAM: MD/CD/32X — RAM 68000 (64 КиБ, FF0000),
SMS/Game Gear — C000 (до 8 КиБ), SG-1000 — доступный объём основной RAM.
Память SH-2, Z80 MD, CD Word-RAM/PRG-RAM и картриджная SRAM этим поиском не охватываются.
Поддержаны беззнаковые 1/2/4-байтные значения, десятичный ввод или `0xHEX`, точное число,
изменение/сохранение/увеличение/уменьшение относительно предыдущего ручного поиска.
В окне показаны первые 256 кандидатов и полное число найденных; последующее отсеивание
всегда работает по всему набору. Снимки и кандидаты освобождаются при закрытии или смене игры.
Нет таймера и постоянного сканирования. Выбранный адрес можно сохранить выключенным
или сразу заморозить; выключение доступно в общем списке читов.

Снимок RAM берётся между кадрами в потоке эмуляции в логическом порядке байтов CPU.
Генератор кодов учитывает внутренний порядок RAM GPX и создаёт группу побайтовых заморозок:
нулевые старшие байты не теряются, соседние байты не затрагиваются.

По сети изменения списка проходят через хоста, а полный список и галки попадают в
согласованное состояние всех участников, включая подключившихся позже. Действуют
обычные разрешения лобби на общие команды; поиск читов остаётся местным ручным действием.
Неверный или неизменившийся список не запускает повторную синхронизацию.
Сетевой протокол 6: обе стороны должны использовать обновлённую сборку.
Лимит команды читов 2 МиБ; остальные типы пакетов сохранили прежние пределы.
Очередь удерживает не больше 8 МиБ списков читов. Каталог хранится/передаётся при изменении,
не на каждом кадре. Для каталога расширен предел метаданных записи до 4 МиБ;
формат кадра, состояние ядра и совместимость прежних записей не менялись.

Hardcore и активная запись управления сохраняют прежний запрет на изменение читов.
Поиск также недоступен в этих режимах. Пауза при потере фокуса следует общей настройке.

Ориентиры формата и ручного поиска:
- https://docs.libretro.com/guides/cheat-codes/
- https://github.com/libretro/RetroArch/blob/master/cheat_manager.c
- https://fceux.com/web/help/CheatSearch.html

Поддержка импорта ограничена нативными кодами ядра (handler 0). Обработчики RAM/rumble
RetroArch (handler 1), шаблоны XX/?? и неопознанные формы не применяются частично:
вся запись пропускается, а окно показывает пояснение. Файлы ограничены 2 МиБ,
индексы — 0…4095; ошибки всего файла не изменяют текущий список.

Проверка предоставленной папки: 3705 CHT, прочитаны 3703 файла, получены 47829 записей;
3643 записи пропущены (включая дубли, шаблоны и неподдерживаемые формы).
Два файла целиком отклонены: Double Dragon (Game Gear, Action Replay) содержит постороннюю
строку `false`, Ys (SMS) использует другой формат с заголовком в квадратных скобках.
Это проверка разбора файлов, а не проверка игрового эффекта каждого кода.
Подробности и проверки на оригинальных тестовых программах — `cheats-verification.json`.

Импорт принимает UTF-8 и UTF-16 с BOM; для старых файлов без BOM допускается Latin-1
с предупреждением. Кавычки внутри описания восстанавливаются; неоднозначные повторные
поля и повреждённый код исключают всю соответствующую запись. Сокращённые MD `FFxxxx:DD`
понимаются как логические побайтовые записи RAM и переводятся через генератор заморозок;
нативные `AAAAAA:DDDD` сохраняют исходное значение. SMS Game Genie с разделением трёх
трёхзначных частей через `+` восстанавливается в `XXX-XXX-XXX` только для однозначных групп.
